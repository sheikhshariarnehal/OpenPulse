# Surface Brief: OpenPulse Dashboard

- Scope: Dashboard UI & Design System Shell
- Visitor Mode: Operate

## Direction contract

THESIS: The developer analytics platform as a high-density, precision technical instrument bench. It refuses oversized marketing whitespace, generic bubbly SaaS cards, and nested popup menus in favor of immediate 32px data grids, sub-second query feedback, and persistent monospace telemetry readouts.

OWN-WORLD: Obsidian backdrop (#090a0f), hairline zinc borders (#1e2230), subdued slate surfaces (#11131a), crisp cyan accent pulse (#06b6d4), and tabular JetBrains Mono metrics. High-contrast status indicators (emerald #10b981 for healthy 2xx, amber #f59e0b for warning, rose #f43f5e for errors).

STORY: Developers and engineering leads instantly comprehend system ingestion health, investigate real-time event anomalies, filter high-velocity telemetry streams, and inspect query latencies with zero cognitive friction and pure keyboard fluency.

FIRST VIEWPORT: Left 56px collapsed technical navigation rail with chord badges; top 44px breadcrumb bar with active environment pill and global search shortcut; 4 compact KPI stat blocks (Ingestion Latency 0.42ms, Events/sec 32.4k/s, Active Clusters 8, Error Rate 0.02%); central high-precision event throughput waveform; bottom dense live event table with millisecond timestamps and expandable JSON drawer.

FORM: Precision Instrument Bench, top grounded candidate (seed key 6653f2bf).

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
